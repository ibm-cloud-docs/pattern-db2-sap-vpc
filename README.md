# pattern-db2-sap-vpc
Documentation repository for pattern-db2-sap-vpc

Two documents are contained within this repository

- pattern-db2-suse-vpc:  This document addresses the case of deploying a highly available instance of Db2 running on SUSE Linux Enterprise Server within an IBM Cloud VPC environment.

- pattern-db2-sap-vpc:  This document builds upon the former (pattern-db2-suse-vpc) to add the deployment of a highly available SAP setup into the environment using the same approach to deliver high availability.
